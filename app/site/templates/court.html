How this works

The cases come from the Court's own {% if source %}Granted & Noted list{% else %}Granted & Noted list{% endif %}; what each is about comes from its question presented on Wikipedia's {{ wiki }} (CC BY-SA 4.0), which our local language model puts in a few plain words. Both are checked weekly.

Headlines that name the Court or a justice are read by the model with the outlet and its country: whether each is about the US Supreme Court, which of the term's cases it's about, a few topic words, and the stage it reports ({% for stage, emoji in stage_emoji.items() %}{{ emoji }} {{ stage }}{% if not loop.last %}, {% endif %}{% endfor %}). A headline joins a case only if it shares a word specific to that case (its parties, place or subject) and the model, asked again about that case alone, agrees. The lean meter is against all the Court coverage, with each outlet counted once per card; each side's framing is its most loaded headline.
