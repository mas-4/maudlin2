How this works

Headlines that name the Court or a justice are read by our local language model, which says whether each is about the US Supreme Court (not a state's or another country's), what case or issue it's about, and which stage it reports: {% for stage, emoji in stage_emoji.items() %}{{ emoji }} {{ stage }}{% if not loop.last %}, {% endif %}{% endfor %}.

The cases come from the Court's own {% if source %}Granted & Noted list{% else %}Granted & Noted list{% endif %}, checked weekly. A headline joins a case when it names a party only that case has ("Suncor", not "Congress"); one that names no party is shown the cases already in the news, with their headlines, and the model says which one it's about, if any ("by issue"). The meter counts each outlet once per case, by its AllSides rating.
